## 一、项目背景
- 本人独立负责某**大型金融电商项目**中「智能体编排子系统」的整体设计与实现，是该系统在推荐与决策侧的核心工程落地。
- 核心诉求：在保持传统后端**强一致、可解释、稳定**的前提下，引入 **LLM 辅助**推荐与跨域决策环节，提升个性化与智能化体验——定位是「LLM 辅助传统后端业务、而非替换」，LLM 仅叠加在确定性管线之上并带降级。
- 系统以 **PoC** 形态交付，外部依赖 **Neo4j / Milvus / Redis / PostgreSQL** 均真实运行，满足真实企业工程验收要求。
- 技术栈：FastAPI 后端 + LangGraph 编排 + 多模型路由（DeepSeek-V3 等大模型），配套四层安全网关与可观测链路。

## 二、技术架构（LLM + 确定性混合）
采用「LLM 智能体 + 确定性链路」混合范式，按问题域分层选型、明确边界：

1. **推荐主链路 · LLM 无条件介入**：`ProductRecAgent`（语义重排）+ `MarketingCopyAgent`（营销文案）在配置开启后真实进入推荐主链路、无额外门控，直接提升召回结果的语义相关性与文案质量。
2. **跨域灰度仲裁 · LLM 条件性触发**：`MetaAgent` 仅在风险灰度区间 / 跨域冲突场景触发 LLM 仲裁，避免对全量请求引入不确定开销。
3. **强一致路径 · 确定性兜底**：风控规则引擎、分期授信、退款、Saga 履约一致性等不触发 LLM，由确定性 Service 保障可复现与稳定。

支撑能力：
- **推荐编排图**：LangGraph 编排多策略召回（向量 Milvus / 协同过滤 Redis / 知识图谱 Neo4j / 热度），并行 fan-out + fan-in。
- **意图路由＝确定性分发器**：显式 `intent` 字段 + 关键词规则分发，LLM 兜底默认关闭，确保不依赖 LLM 理解自然语言即可正确走链路。
- **四层安全网关**：限流（fail-closed）→ JWT 鉴权 → PII 脱敏 → Prompt 注入检测。
- **履约一致性**：Saga 事务（含补偿与熔断）、条件写门控（仅授信批准才落单）。
- **实验与评估**：A/B（Thompson Sampling）框架 + 离线/在线评测体系（Precision@K、NDCG@K 等）。

## 三、个人贡献
- **基于 Neo4j 知识图谱构建用户画像服务，以 Cypher 特征查询 + RFM 确定性规则引擎完全替代旧版 LLM 黑盒分群推断**：画像构建 100% 可复现，每个分群结果附带明确的规则命中原因与特征依据，支持冷启动上下文兜底；画像构建耗时较 LLM 方案降低 10–20 倍。
- **通过协同过滤 + 知识图谱多跳召回 + Milvus 向量 ANN + 热度/新品策略多路召回，去重合并形成候选集**；再以 GraphRAG 子图路径（商品关联关系、多跳路径、相似用户、图谱得分）作为上下文注入 LLM 语义重排，增强排序可解释性——实现「多路召回 + 精排」推荐架构，LLM 重排失败自动回退确定性排序。
- **基于 LangGraph StateGraph 构建多 Agent 协同拓扑，梳理推荐、风控、履约等多领域任务协作流程**：
  - 并行分发用户画像 / 多策略召回（Stage1）、LLM 重排 / 库存校验（Stage2）等节点，结果经 channel reducer 聚合后由 A/B 引擎（Thompson Sampling + 一致性哈希分桶）分流，支持「规则重排 vs LLM 重排」实验组切换，最终串行生成营销文案（Stage3）。
  - 设计统一入口，意图路由器识别推荐 / 反欺诈 / 授信 / 退款 / 履约五大场景，条件边动态选择对应 Agent 链路，支持领域分支动态扩展。
  - 跨领域结果冲突或灰度区间风险时由 Meta-Agent 仲裁（规则快通道 + LLM 灰度仲裁双路径），输出 approve / escalate / reject 最终决策，并落条件写门控。
  - 为所有 Agent 统一实现 BaseAgent 基类，内置指数退避重试、独立超时、确定性降级、滑动窗口熔断四层防护，LLM 故障自动降级、主链路不中断。
